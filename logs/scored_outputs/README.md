# Scored Output Files

This folder contains copied per-question CSV outputs from scored validation
runs.

Included files:

- `per_question.csv`
- `per_question_venv.csv`
- `final_validation_predictions_best_adapter_per_question.csv`
- `final_validation_predictions_best_adapter_gated_per_question.csv`
- `composed_gated_per_question.csv`

These CSVs are the evaluator outputs corresponding to the JSON prediction files
kept in `logs/raw_outputs/`.
